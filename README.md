# FLORES - Regalo especial

Proyecto web emotivo y visualmente atractivo para dedicar a una persona especial. La página incluye una introducción con saludo, una escena de flores animadas y una carta interactiva que se mueve por la pantalla y abre un mensaje al hacer clic.

## Características
- Animación visual con flores y fondo nocturno
- Carta flotante interactiva
- Modal con mensaje personalizado
- Diseño responsive
- Estructura simple en HTML, CSS y JavaScript puro

## Estructura del proyecto
- `index.html`: entrada principal con redirección
- `Flores_NilverTI/index.html`: pantalla inicial del proyecto
- `Flores_NilverTI/FLORES.html`: escena principal con flores y carta
- `Flores_NilverTI/css/`: estilos del proyecto
- `Flores_NilverTI/img/`: imágenes y recursos visuales

## Cómo ejecutarlo localmente
1. Abre una terminal en la carpeta del proyecto.
2. Ejecuta:

```bash
cd "C:\Users\DAVID\Downloads\FLORES-main\Flores_NilverTI"
python -m http.server 8001
```

3. Abre en el navegador:

```text
http://localhost:8001/FLORES.html
```

## Nota importante
La versión funcional del proyecto está dentro de la carpeta `Flores_NilverTI/` y es la que debe usarse como base para visualizar y desplegar la página.

## Créditos
- Inspiración visual basada en efectos de flor y animación CSS.
- Adaptación y personalización para un regalo especial.
